# Food Allergy Detection System

A machine learning-based application for food allergy risk detection using Python, NLP, TensorFlow, Scikit-learn, and Streamlit.

## Project Overview

This project analyzes food allergy-related information and symptoms to estimate allergy risk. It combines machine learning and NLP techniques with an interactive Streamlit interface.

## Features

- Symptom-based allergy risk prediction
- Food allergy classification
- NLP-based symptom processing
- Personalized nutritional alternatives
- Recipe recommendation functionality
- Interactive Streamlit interface

## Technologies Used

- Python
- TensorFlow
- Scikit-learn
- NLP
- Streamlit
- Pandas
- NumPy
- MySQL

## Project Structure

- `app.py` - Main application
- `auth.py` - Authentication functionality
- `nutritional_alternatives.py` - Nutritional alternatives
- `recipe_recommender.py` - Recipe recommendation
- `train_model.py` - Model training
- `train_symptom.py` - Symptom model training
- `requirements.txt` - Python dependencies
- `model/` - Trained machine learning models
